# Proposal

## Why

目前訂單主檔與明細模組（http://localhost:8080/order）在呈現與操作體驗上有數項待優化之處：
1. 訂單清單預設依建立時間倒序排列，未能依訂單編號由小到大（遞增）排序，不利於依照單號循序檢索。
2. 訂單總額欄位在表格渲染時夾帶了 `<strong>57,000</strong>` 網頁標籤，由於通用表格組件使用純文字防護，導致標籤字串直接外露於畫面上。
3. 新增訂單時，客戶編號與業務員工編號為自由文字輸入，缺乏下拉式選單與資料防呆；訂單明細品項輸入區未清楚顯示欄位名稱；折讓欄位為任意數值輸入，未限定特定選項。
4. 訂單明細彈窗僅提供唯讀檢視，缺乏針對訂單明細行之欄位修改（數量、折讓）及新增產品功能。

## What Changes

- **訂單編號排序優化**：訂單主檔清單（分頁查詢與前端視圖）預設依照訂單編號（orderId）由小到大依序排列（ASC）。
- **訂單總額標籤移除**：移除訂單總額中的 `<strong>` 網頁標籤，直接顯示清晰格式化之數值（例如 `57,000`），杜絕 HTML 標籤外露。
- **新增訂單表單優化**：
  - 客戶編號與業務員工編號改為下拉式選單（select），自動動態加載客戶主檔與員工主檔之資料（顯示編號與名稱）。
  - 訂單明細品項落實欄位名稱的明確顯示（包含產品編號/選擇產品、數量、折讓、操作等標題）。
  - 折讓欄位採用下拉式選單，僅提供 `0`、`5`、`75` 三種選項。
- **訂單明細功能擴充（欄位修改與新增產品）**：
  - 訂單明細視窗提供明細行各欄位修改功能（數量、折讓調整）。
  - 訂單明細視窗提供「新增產品」功能，可於現有訂單中追加產品品項。
  - 折讓欄位同步限定僅提供 `0`、`5`、`75` 下拉式選單選項。
  - 儲存修改時同步更新後端訂單明細實體並自動重新計算訂單總額（totalAmount）。

### Modified Capabilities
- `mofei-erp-master-data`: 擴充訂單主檔與明細規範，涵蓋訂單編號遞增排序、訂單總額純文字數值呈現、新增訂單之客戶與業務下拉選單、明細欄位名稱顯示、折讓固定下拉選項（0, 5, 75）、以及訂單明細修改與新增產品之業務規則。

## Impact

- **後端程式碼**：
  - `OrderServiceImpl.java`: 訂單查詢預設排序改為 `orderByAsc(Orders::getOrderId)`；完善 `update` 方法以支援訂單明細的更新、新增品項、折讓檢核與訂單總額重新計算。
- **前端視圖與腳本**：
  - `templates/order.html`: 
    - 修正表格 `totalAmount` 欄位渲染，移除 `<strong>` 標籤。
    - 新增訂單彈窗：客戶與業務員工改為下拉選單並非同步載入資料；明細品項新增明確欄位表頭；折讓改為下拉選單（0, 5, 75）。
    - 訂單明細彈窗：由純檢視升級為支援欄位修改（數量、折讓下拉）、新增產品、行項目刪除與儲存更新。
- **測試案例**：
  - `MasterDataApiTest.java`: 補充訂單編號遞增排序、訂單明細修改、新增產品與金額重算之測試驗證。
