# Proposal

## Why

在新增銷售訂單時（http://localhost:8080/order），目前使用者在下拉選單選擇客戶後，仍需手動輸入收件人姓名、電話、配送地址以及手動選擇負責業務員工，缺乏自動帶入機制，增加重複輸入負擔並易造成資料不一致。此外，新增訂單彈窗中的訂單明細品項未提供小計與整張訂單之即時總金額試算，使用者在填寫過程中無法立即預覽訂單總額，影響開單效率與確認體驗。

## What Changes

- **選擇客戶自動帶入客戶資訊與業務經辦**：
  - 在新增訂單彈窗中，當使用者選取「下單客戶」時，系統自動將客戶主檔之資訊帶入表單：
    - 收件人姓名（`recipientName`）：自動填入客戶名稱。
    - 收件人電話（`recipientPhone`）：自動填入客戶聯絡電話。
    - 完整收件地址（`recipientAddress`）：自動填入客戶完整地址（組合國家、城市、行政區與詳細地址）。
    - 業務員工（`employeeId`）：自動切換「業務員工」下拉選單為該客戶所關聯之業務人員。
- **訂單明細即時試算與總金額顯示**：
  - 在新增訂單明細各品項行中，當選取產品、修改數量或調整折讓（0, 5, 75）時，即時計算並呈現該行品項小計（單價 × 數量 - 折讓）。
  - 在新增訂單彈窗底部新增「訂單預估總額：NT$ [金額]」即時統計區塊，隨品項內容變動、新增品項或刪除品項即時同步重新計算。

### Modified Capabilities
- `mofei-erp-master-data`: 擴充新增訂單行為規範，包含選擇客戶時之自動帶入聯動（收件人姓名、電話、地址與負責業務員工），以及新增訂單明細行項目小計與訂單預估總額之即時動態計算。

## Impact

- **前端視圖與腳本**：
  - `templates/order.html`: 
    - 增加客戶選單變更事件監聽（`onCustomerChange`），自動填入收件人資訊與業務員工。
    - 明細輸入行增加小計顯示與即時計算（`recalcCreateModalTotal`），表單底部增加預估總金額統計。
- **測試案例**：
  - 補充客戶資訊自動帶入與明細小計/總額即時試算之驗證。
