## 三、 漏洞發現與修復紀錄

1. **[發現點]**：初始資料庫插入腳本因 PowerShell 雙引號字串展開特性，導致 BCrypt 雜湊值中之 `$` 被誤認為變數而截斷。
   - **修復方式**：修正腳本字串為單引號字面值 (`@' ... '@`)，並於資料庫與 `data.sql` 中重新更新為驗證通過之標準 BCrypt 雜湊值。
   - **驗證結果**：`SecurityTest` 驗證登入成功並正確簽發 Cookie。

2. **[發現點]**：MyBatis-Plus 全局 `logic-delete-field` 在 NVARCHAR 欄位上配置 `N'在職'` 導致 MSSQL 語法解析異常。
   - **修復方式**：移除全域 logic-delete 配置，於業務 Service 層顯式實作在職狀態切換與軟刪除控制。
   - **驗證結果**：全數單元與整合測試順利通過，SQL 執行無任何語法錯誤。
